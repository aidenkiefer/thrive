# Session log: `cursor/experience-motion`

**Assignment:** owner request 2026-11-18 ("tasteful animations and transitions, subtle but noticeable, smooth, performant, responsive") · **Lane:** experience · **Tool:** cursor · **Stacked on:** `cursor/experience-draft-handoff` (PR #24)

## Entries
- `22:40` **decision**: CSS-only motion, no new dependency, no client JavaScript. Everything animates `transform`/`translate`/`opacity` (compositor-only), uses one shared easing (`--ease-out`), and is gated by `prefers-reduced-motion`. Scroll reveals use native scroll-driven animations (`animation-timeline: view()`); browsers without support (currently Firefox) show static content, so nothing is hidden by a failed script. The `translate` property is used so reveals compose with hover `transform` on the same element.
- `22:45` **change**: motion system in `src/app/globals.css`: scroll reveals (`.reveal`, `.reveal-stagger`, `.reveal-late`), hero load-in (`.hero-enter`: text staggers; the h1 only slides, no fade, so it paints immediately for LCP), hero photo settle plus a light scroll parallax (`.hero-bg*`), card lift on whole-card links (`.motion-lift`, hover devices only), button press and 1px hover lift (`.press`), mobile drawer entrance (`.drawer-in`), smooth anchor scrolling with a sticky-header offset, and a loading skeleton (`.skeleton`).
- `22:50` **change**: applied to the content kit (SectionIntro, FeatureSplit, PullQuote, StepList, CtaBand, MapEmbed, CardGrid, PeopleGrid), homepage sections, list pages (groups, outreach, sermons, series), `PageHero`, buttons (shared Button, LinkButton, hero and nav actions, newsletter), nav underline slide, and card links (event, sermon, upcoming events, InfoCard links only). New `src/app/(public)/loading.tsx` skeleton shown only while dynamic pages stream.
- `22:55` **note**: verification on a production build in a real browser: 25 reveal elements on `/` start hidden below the fold and all finish at full opacity when scrolled into view; reveals use ViewTimeline, parallax uses ScrollTimeline; 12 routes at 1280px and 375px have zero stuck-hidden elements and no horizontal overflow; with `prefers-reduced-motion: reduce` all content is visible, 0 scroll-driven animations, 0 running animations, smooth scroll off. Gate PASS (33 tests on this branch, 4 pre-existing lint warnings).
- `22:55` **note**: not verified: data-backed list grids with real records (empty without a database; same classes apply), Firefox/Safari rendering, real-device frame rate, Lighthouse/CLS numbers. Transform and opacity changes cannot shift layout, so CLS risk is low but unmeasured.
- `22:55` **note**: decided against a page-to-page fade transition: a `template.tsx` opacity fade would delay LCP on every navigation, and Next's view-transition support is still experimental.
