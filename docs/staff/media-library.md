# Media library

Open **Media library** from the admin sidebar or dashboard. The library includes church photo originals, web-ready photos, artwork, brand assets and app icons stored in the project. Different versions of the same photo can appear because both originals and website copies are included.

- The grid uses three columns on desktop and two on narrower screens.
- Select a thumbnail to open the full image against a darkened background.
- Use the previous/next buttons, left/right arrow keys or a horizontal swipe to browse. Navigation wraps at the first and last image.
- Close with the top-right X or Escape. Keyboard focus returns to the thumbnail you opened.

This view is for browsing. It does not upload, delete, edit or apply an image to a website page. Request a content edit separately when you decide which photo to use. Image availability in this library does not add licensing or consent beyond the existing source approval.
