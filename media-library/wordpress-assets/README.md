# WordPress migration assets

The following 12 assets were supplied in `migration-assets` and converted to WebP without resizing. Graphics with transparency use lossless WebP; photographic images use WebP quality 85. The original files remain in the source folder. `.crdownload` indicates Chrome named those files as downloads in progress; image decoding and file end markers were checked before conversion.

The five Flames graphics and overview relate to the [existing Thrive Flames page](https://thrivevineyard.com/thrive-flames/), which still needs to be migrated. The white marks require a contrasting background.

- **cropped-thrive-favicon.webp** ← `cropped-thrive-favicon.png.crdownload` — White Thrive symbol, cropped favicon variant.
- **Engage.webp** ← `Engage.png.crdownload` — Thrive Flames: mission, seeking the lost and caring for the poor.
- **ExpressoServiceThumb-scaled.webp** ← `ExpressoServiceThumb-scaled.jpg.crdownload` — Express(o) service artwork; contains an 8:30 AM time, verify before use.
